# 🎮 Last Zone — Battle Royale

A browser-based 2D battle-royale game inspired by the battle-royale genre.

You fight enemy bots, collect supplies, stay inside the shrinking safe zone, and try to become the last player alive.

---

## 🎯 Features

- 🧍 Player movement
- 🔫 Shooting system
- 🔄 Reloading
- 🤖 Enemy bots
- ❤️ Health system
- 💥 Damage system
- 📦 Ammo pickups
- 💚 Health pickups
- ⭕ Shrinking safe zone
- 🏆 Victory system
- 💀 Elimination system
- 📱 Mobile controls
- 🖥️ Desktop controls
- 🌐 Runs directly in a web browser
- 🚫 No external libraries required

---

## 🎮 Controls

### 🖥️ Desktop

| Action | Control |
|---|---|
| Move | W A S D |
| Move | Arrow Keys |
| Aim | Mouse |
| Shoot | Left Mouse Button |
| Reload | R |

### 📱 Mobile

- Use the **left joystick** to move.
- Touch the game area to aim/shoot.
- Use the **reload button** to reload.

---

## 🚀 How to Play

1. Open the game.
2. Press **PLAY**.
3. Move around the map.
4. Find and eliminate enemy bots.
5. Collect ammo and health.
6. Stay inside the blue safe zone.
7. The safe zone gets smaller over time.
8. Eliminate everyone else.
9. Become the last player alive! 🏆

🌐 Publish With GitHub Pages

Step 1

Create a new GitHub repository.

For example:

last-zone

Step 2

Upload these files:

index.html
style.css
game.js
README.md

Step 3

Open your repository's:

Settings → Pages

Step 4

Under Build and deployment, select:

Deploy from a branch

Choose:

Branch: main
Folder: / (root)

Then click Save.

Step 5

Wait for GitHub Pages to deploy your website.

GitHub will provide a URL similar to:

https://YOUR-USERNAME.github.io/last-zone/

Open that URL and your game will be playable online. 🎮
